
# Laboratorio 1 - Fundamentos de Programación

## Gestionando proyectos colaborativos con Git y GitHub

### Descripción
Este proyecto corresponde al Laboratorio 1 del curso Fundamentos de Programación.

El objetivo es aprender a utilizar Git y GitHub para gestionar proyectos de programación mediante repositorios, commits, ramas y pull requests.

### Herramientas utilizadas
- Git
- GitHub
- Visual Studio Code
- Python

### Desarrollo
Se creó un repositorio local y se conectó con un repositorio remoto en GitHub.

Posteriormente, se creó la rama `funcionalidad`, donde se desarrolló un programa sencillo en Python que muestra un mensaje de bienvenida.

Finalmente, se realizó un commit, se subió la rama al repositorio remoto y se integraron los cambios mediante un Pull Request.
